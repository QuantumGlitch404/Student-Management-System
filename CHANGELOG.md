# Changelog
All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-20
### Added
- Initial release of Student Management System.
- Admin, Faculty, Student, Parent roles.
- Profile management with photo upload, tabs, completeness meter.
- Per-course fee structures with versioning and publish/restore.
- Timetable templates, exceptions, conflict detection, version history.
- Mail Center with three-pane client, templates, campaigns, IMAP/SMTP sync.
- Help Center with 384 articles in English, Hindi, Hinglish; 684 FAQs.
- Announcements, notifications, activity logs, audit trails.
- Razorpay integration (test/live), Google sign-in, AI assistant.
- Export engine (PDF, Excel, CSV, ICS).
- Background services (mail sync, ticker, cleanup).
- Installer with first-run setup wizard.

### Fixed
- Mail Center Templates crash and sign-out issue.
- Mail send HTML encoding and default account label.
- Help language switch persistence and search.
- Student profile tabs, contrast, locked fields.
- PDF date-only timestamps.
