# Security Policy
## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✓                  |

## Reporting a Vulnerability
Please report security vulnerabilities to security@quantumglitch404.example (or via GitHub Security Advisories). Do not open public issues for security problems.

We will acknowledge receipt within 48 hours and provide a fix timeline.
